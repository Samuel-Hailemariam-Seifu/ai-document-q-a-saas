## Frontend (React + Vite + Tailwind)

### Prereqs
- Node.js 20+

### Setup
```bash
cd frontend
npm install
```

### Environment
Create `.env` from `.env.example` and set:

```env
VITE_API_BASE_URL=http://localhost:8000
```

### Run dev server
```bash
npm run dev
```

Frontend runs at `http://localhost:5173`.
